Дополнительно

Ключ сохраняется в этом браузере после подтверждения кнопкой. Повторное подключение использует сохранённую привязку.

Ключ считается из имени, которое самокат отдаёт по Bluetooth. Если привязка не идёт — проверьте это поле.

Рекомендуется 40 мс — проверено на Mi Scooter 3. По умолчанию: 0 мс, без задержки.
