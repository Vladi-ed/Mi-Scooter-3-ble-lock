# Mi3 BLE Locker

Веб-пульт для Xiaomi Mi Scooter 3: подключение по Bluetooth LE, привязка
кнопкой питания, блокировка и разблокировка, чтение батареи,
прошивки и серийного номера. Приложение полностью статическое, работает
в браузере и не требует сервера или установки зависимостей.

![Пульт в демо-режиме](docs/screenshot-main.png)

## Запуск

Для iPhone проверялось подключение через **Bluefy**. Нужны разрешение
Bluetooth, включённый самокат рядом и HTTPS-страница. Закройте Mi Home
и другие приложения, которые могут удерживать BLE-соединение.

1. Откройте страницу в Bluefy и нажмите **«Выбрать самокат»**.
2. Разрешите Bluetooth и выберите своё устройство. Разрешите системное
   сопряжение, если браузер его запросит.
3. Когда появится приглашение, коротко нажмите кнопку питания самоката.
4. Дождитесь завершения привязки, затем используйте кнопки замка.

При повторном запуске кнопка подключения использует сохранённое устройство.
Если оно переименовано или нужно выбрать другое, нажмите **«Другое устройство»**.
Подключение требует действия пользователя; фоновое подключение не предусмотрено.

На компьютере нужен браузер с Web Bluetooth, например Chrome или Edge,
и поддерживаемый Bluetooth-адаптер. Для локального запуска можно использовать
любой статический HTTP-сервер.

Для iPhone используйте HTTPS-хостинг.

## Демо и настройки

Кнопка **«Демо без самоката»** или параметр `?demo=1` запускают виртуальный
самокат. Демо позволяет проверить интерфейс, привязку, команды и журнал
без Bluetooth, но не подтверждает работу реального устройства.

В блоке **«Дополнительно»** доступны имя Bluetooth для AES, режим протокола,
метод GATT-записи, разбиение кадров и пауза между частями.

- Основной протокол — **Ninebot AES**. Имя для ключа должно совпадать
  с фактическим Bluetooth-именем самоката; после изменения переподключитесь.
- Оставьте GATT-запись в режиме **«Авто»** и разбиение длинных кадров по 20 байт.
- Пауза по умолчанию — **0 мс**. В успешной аппаратной проверке использовались
  **40 мс**; это отдельная проверенная настройка, а не значение по умолчанию.
- Режим отправки целого длинного кадра зависит от BLE-стека и может приводить
  к разрыву соединения.

Если нет ответа, проверьте имя для AES, питание, разрешение Bluetooth
и отсутствие другого подключённого приложения. Переподключитесь после
изменения настроек. Один таймаут не определяет причину отказа.

## Диагностика и KERS

После подключения откройте **«Расширенная диагностика» → «Диагностика»**.
Приложение читает версии DRV/BLE, пробег, напряжение, температуру контроллера,
коды ошибок и предупреждений, флаги состояния и уровень рекуперации.
Неответивший регистр показывается как «Нет ответа», а не как нулевое значение.
Единицы рассчитаны по карте Ninebot; для конкретной прошивки Mi 3 нужна проверка.
Отчёт JSON содержит показатели и настройки транспорта, без идентификаторов
устройства и материала привязки.

KERS доступен после успешного чтения уровня 0–2. Выберите слабую, среднюю
или сильную рекуперацию и нажмите **«Применить»** на неподвижном самокате.
Запись выполняется один раз, затем уровень проверяется чтением.
Ответ на запись без совпадающего чтения не считается подтверждением настройки.

Операции статуса, диагностики, KERS и замка выполняются последовательно.
При отключении ожидающие команды отменяются. После таймаута повторное чтение
того же регистра требует переподключения, чтобы запоздалый ответ не был принят
за новый. Подробности сравнения SHU и сценарий аппаратной проверки —
в [сравнении профилей](docs/shu-profiles.md).

## Хранение данных и журнал

В `localStorage` этого сайта сохраняются настройки, имя и браузерный id
последнего устройства. После подтверждённой привязки сохраняются также
имя, серийный номер и 16 байт `appRandom`, необходимые для повторного
подключения без кнопки. Сессионный AES-ключ, BLE random и счётчик
между соединениями не сохраняются. Приложение не отправляет эти данные на сервер.

**«Забыть привязку»** удаляет сохранённый ключ текущего самоката. Для полного
удаления настроек и списка сохранённых привязок очистите данные сайта
в браузере. На другом домене, в другом браузере или после очистки данных
потребуется новая привязка. Самокаты, переименованные по Bluetooth,
также могут потребовать повторного подтверждения.

Обычный журнал показывает события и результаты команд. При копировании
в обычном режиме известные приложению имя, id и серийник скрываются,
raw-пакеты исключаются. Перед отправкой всё равно проверьте текст:
это не гарантия полной анонимности, а на экране остаются исходные события.
Режим **«подробно»** добавляет пакеты и GATT-обмен; он может раскрывать имя, серийный номер
и материал привязки, включая его байтовое представление. Не публикуйте
подробные журналы, снимки хранилища или скриншоты с личными данными.
Описывайте неполадки по [шаблону отчёта](.github/ISSUE_TEMPLATE/bug_report.yml).

## Проверенные возможности и ограничения

На Mi Scooter 3 через Bluefy подтверждались полная привязка, чтение данных
и физическое выполнение блокировки и разблокировки. Точные версии iOS 26
и Bluefy для этой проверки не зафиксированы.

Повторная привязка без кнопки и состояние замка через регистр `0x1D`
подтверждены аппаратными журналами. Подтверждение приёма команды и фактическое
состояние замка отображаются отдельно. Проверяйте результат на самом самокате.
Восстановление после пропущенных ответов и подтверждение изменения KERS
требуют дальнейшей проверки на устройстве.

Работа с другими моделями, прошивками и браузерами не гарантируется.
Используйте только собственный самокат; проверяйте команды на неподвижном
устройстве с вывешенным ведущим колесом. Электронная блокировка не заменяет
физический противоугонный замок.
